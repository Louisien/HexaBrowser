# Hexa Browser 🚀

Hexa Browser is a 100% French, open-source web browser that respects your privacy and integrates AI tools like Mistral models. It is designed to provide a secure and private browsing experience without directly generating profits.

## Features ✨

- **Privacy-Focused**: Respects and protects your privacy.
- **AI Integration**: Utilizes AI tools like Mistral models.
- **Open-Source**: Completely open-source and community-driven.
- **Non-Profit**: Focused on user experience, not profit.
- **Supported Platforms**: Windows, MacOS, Linux/Android.
